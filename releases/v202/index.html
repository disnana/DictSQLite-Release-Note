DictSQLite v2.0.2

リリース日: 2025年10月20日
タイプ: マイナーリリース

🚀 新機能

辞書互換API実装

標準的なPython辞書と同じインターフェースで操作できるメソッドを追加しました。

  • items() - (key, value)タプルのイテレータを返す
  • values() - 全値のイテレータを返す
  • update(dict) - 辞書で一括更新
  • pop(key, default=None) - キーを削除して値を返す
  • setdefault(key, default=None) - キーが存在しない場合のみデフォルト値を設定
from dictsqlite import DictSQLite

db = DictSQLite('data.db')

# 辞書と同じように使える
db.update({'key1': 'value1', 'key2': 'value2'})
print(list(db.items()))  # [('key1', 'value1'), ('key2', 'value2')]
print(list(db.values()))  # ['value1', 'value2']

value = db.pop('key1', 'default')
db.setdefault('new_key', 'default_value')

🔧 改善点

v1.8.8との互換性強化

  • v1.8.8で使用していたコードをほぼそのまま移行可能に
  • 辞書互換メソッドにより、既存のPythonコードとの統合が容易に

永続化モード対応

  • 追加されたメソッドは全ての永続化モード（Memory/Lazy/WriteThrough）で動作
  • 各モードの特性に応じた最適化を実施

📊 パフォーマンス

新しいメソッドもRust実装の高速性を維持:

  • update(): バルク挿入により高速動作
  • items()/values(): イテレータにより省メモリ
  • v2.0.1のパフォーマンス特性を維持

📖 互換性

  • Python 3.9以上
  • v2.0.0、v2.0.1との完全な互換性を維持

📝 使用例

from dictsqlite import DictSQLite

db = DictSQLite('data.db')

# v1.8.8スタイルの辞書操作がそのまま使える
data = {'name': 'Alice', 'age': 30, 'city': 'Tokyo'}
db.update(data)

# イテレーション
for key, value in db.items():
    print(f"{key}: {value}")

# デフォルト値の設定
db.setdefault('country', 'Japan')
