DictSQLite v1.3.3

リリース日: 2025年8月1日（推定）
タイプ: パッチリリース

🏗️ 基本機能の確立

💾 コア機能

  • 辞書風インターフェース: SQLiteを辞書のように操作する基本機能
  • キー・バリュー操作: 基本的なget/set/delete操作
  • データ永続化: 自動的なSQLiteファイルへの保存

🔧 基本API

  • __getitem__ / __setitem__: 辞書風のアクセス
  • __delitem__: キーの削除
  • __contains__: キー存在確認
  • keys() / values() / items(): 辞書メソッド

📖 使用方法

基本的な操作

from dictsqlite import DictSQLite

# データベースファイルの作成
db = DictSQLite('mydata.db')

# 基本的なデータ操作
db['name'] = 'Alice'
db['age'] = 30
db['active'] = True

# データの読み取り
print(db['name'])  # 'Alice'
print('age' in db)  # True

# データの削除
del db['active']

# すべてのキーの取得
for key in db.keys():
    print(f"{key}: {db[key]}")

# データベースのクローズ
db.close()

複合データの保存

# 辞書やリストの保存
db['user_info'] = {
    'name': 'Bob',
    'hobbies': ['reading', 'coding', 'music'],
    'address': {
        'city': 'Tokyo',
        'zip': '123-4567'
    }
}

# ネストされたデータの取得
user = db['user_info']
print(user['address']['city'])  # 'Tokyo'

🔧 技術的詳細

データ保存方式

  • Pickle serialization: Pythonオブジェクトの直接保存
  • SQLite backend: 信頼性の高いSQLiteデータベース
  • 自動型変換: Python型の自動的な保存・復元

ファイル構造

-- 自動生成されるテーブル構造
CREATE TABLE IF NOT EXISTS data (
    key TEXT PRIMARY KEY,
    value BLOB
);

エラーハンドリング

# キーが存在しない場合
try:
    value = db['nonexistent_key']
except KeyError:
    print("キーが見つかりません")

# より安全なアクセス
value = db.get('maybe_key', 'default_value')

🛡️ 安定性と制限

安定した機能

  • 基本的なCRUD操作: 読み書き削除は安定
  • データ永続性: ファイル保存は確実
  • 型サポート: 基本的なPython型をサポート

現在の制限

  • 並行アクセス: 複数プロセスからの同時アクセスは未対応
  • 暗号化: データ暗号化機能なし
  • トランザクション: 高度なトランザクション機能なし
  • インデックス: 検索最適化機能なし

📊 パフォーマンス特性

適用範囲

  • 小〜中規模データ: 数千〜数万件のレコード
  • シンプルな用途: 設定ファイル、キャッシュ、簡単なデータ保存
  • 単一プロセス: 一つのプロセスからのアクセス

ベンチマーク例

import time
from dictsqlite import DictSQLite

# 基本的なパフォーマンステスト
db = DictSQLite('test.db')

# 書き込み性能
start = time.time()
for i in range(1000):
    db[f'key_{i}'] = f'value_{i}'
write_time = time.time() - start

# 読み込み性能
start = time.time()
for i in range(1000):
    _ = db[f'key_{i}']
read_time = time.time() - start

print(f"書き込み: {write_time:.2f}s, 読み込み: {read_time:.2f}s")

🔧 インストールと要件

インストール

pip install dictsqlite==1.3.3

依存関係

  • Python 3.7+: Python 3.7以上が必要
  • SQLite3: Pythonの標準ライブラリ（追加インストール不要）

🔍 既知の問題

制限事項

  • Large objects: 非常に大きなオブジェクトでの性能低下
  • Complex objects: 一部の複雑なオブジェクトで保存エラー
  • File locking: ファイルロック機能の不完全性

回避策

# 大きなデータの分割保存
large_data = list(range(100000))
chunk_size = 1000

for i, chunk_start in enumerate(range(0, len(large_data), chunk_size)):
    chunk = large_data[chunk_start:chunk_start + chunk_size]
    db[f'chunk_{i}'] = chunk
