🚀 使用方法

インストールまたはアップグレード:

pip install --upgrade dictsqlite

既存のコードはそのまま動作します:

from dictsqlite import DictSQLite

db = DictSQLite('data.db')
db['key'] = 'value'
print(db['key'])  # 'value'
