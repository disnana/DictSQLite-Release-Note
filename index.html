    🛡️ セキュリティ強化

    • サンドボックス実行: 制限された環境でのpickle処理
    • 実行前検証: デシリアライズ前の安全性チェック

    🔧 技術的詳細

    🔐 Safe Pickle 実装

    新しい SafePolicy クラスによる安全なpickle処理：

    from dictsqlite import DictSQLite, SafePolicy, safe_loads

# 安全なpickle設定
db = DictSQLite('secure.db', safe_pickle=True)

# カスタムセーフポリシー
policy = SafePolicy()
policy.allow_class('__builtin__', 'dict')
policy.allow_class('__builtin__', 'list')

# 安全なデータの読み込み
safe_data = safe_loads(pickle_data, policy)

    ⚠️ 制限の詳細

    以下のクラス/モジュールは制限されます：

    • 実行可能コード: exec, eval, compile
    • ファイル操作: open, file
    • システムコール: os.system, subprocess
    • ネットワーク: socket, urllib
    • 任意のクラス: 明示的に許可されていないクラス

    🚀 新機能

    🛠️ SafePickle API

    from dictsqlite.modules.safe_pickle import SafePolicy, safe_loads, safe_dumps

# セーフポリシーの作成
policy = SafePolicy()

# 基本データ型を許可
policy.allow_builtins(['dict', 'list', 'tuple', 'str', 'int', 'float'])

# 安全な保存と読み込み
safe_data = safe_dumps(data, policy)
loaded_data = safe_loads(safe_data, policy)

    🔍 セキュリティログ

    # セキュリティイベントのロギング
db = DictSQLite('secure.db', security_logging=True)

# 不審な活動は自動的にログに記録

print(f"書き込み: {write_time:.2f}s, 読み込み: {read_time:.2f}s")

    🔧 インストールと要件

    インストール

    pip install dictsqlite==1.3.3

    依存関係

    • Python 3.7+: Python 3.7以上が必要
    • SQLite3: Pythonの標準ライブラリ（追加インストール不要）

    🔍 既知の問題

    制限事項

    • Large objects: 非常に大きなオブジェクトでの性能低下
    • Complex objects: 一部の複雑なオブジェクトで保存エラー
    • File locking: ファイルロック機能の不完全性

    回避策

    # 大きなデータの分割保存
large_data = list(range(100000))
chunk_size = 1000

for i, chunk_start in enumerate(range(0, len(large_data), chunk_size)):
    chunk = large_data[chunk_start:chunk_start + chunk_size]
    db[f'chunk_{i}'] = chunk
